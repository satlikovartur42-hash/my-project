# NEXORA CRYPTO

Next.js Telegram Mini App market dashboard. Live prices and conversion via CoinGecko, SVG charts, manual portfolio, favorites, read-only wallet address saving. No custody, trading, or exchange execution.

Install: `npm install` then `npm run dev`.

Environment variables in `.env.example`. Configure Telegram webhook separately. Wallet balances are not fetched yet; wallet addresses are saved locally only.
